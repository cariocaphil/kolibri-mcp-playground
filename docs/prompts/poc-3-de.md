# PoC 3 — KoliBri Formular

Implementiere in `src/App.tsx` ein kleines Formular mit KoliBri-Komponenten.

Das Formular soll enthalten:

- ein Texteingabefeld
- eine Checkbox
- ein Textfeld mit Wortzähler
- einen Submit-Button

Anforderungen:

- Verwende passende KoliBri-Komponenten.
- Füge keine neuen Dependencies hinzu.
- Halte die Implementierung so klein wie möglich.
- Stelle sicher, dass das Projekt erfolgreich gebaut werden kann.
